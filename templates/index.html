Acerca de Minerva Explorador de ICFES

Una Herramienta para el Análisis de Datos Educativos en Colombia

El Instituto Colombiano para la Evaluación de la Educación (ICFES) publica los resultados de las pruebas Saber 11 como datos abiertos, un recurso de inmenso valor para la transparencia. Sin embargo, acceder a las conclusiones que estos datos ofrecen no es una tarea sencilla. La información en su estado original se distribuye en archivos de texto masivos (microdatos) con cientos de miles de registros, que son difíciles de manejar y analizar sin software especializado y conocimientos técnicos.

Para un directivo, docente o padre de familia, la tarea de descargar estos archivos, filtrar la información de un colegio específico y realizar cálculos para obtener promedios o tendencias se convierte en un obstáculo significativo. Minerva nace precisamente para eliminar esa barrera.

Nuestra Misión

Minerva Explorador de ICFES es una herramienta independiente creada con el objetivo de hacer que los datos públicos de las pruebas Saber 11 sean más accesibles, comprensibles y útiles. La misión de este proyecto es ofrecer a directivos, docentes, padres de familia y estudiantes una plataforma clara y potente para explorar y analizar el desempeño académico, fomentando decisiones informadas y una mejor comprensión del panorama educativo.

¿Qué Información Encontrará al Analizar un Colegio?

Al seleccionar un periodo, departamento y colegio, Minerva genera un reporte completo que incluye los siguientes análisis clave:

  • Análisis Comparativo de Promedios: Comparamos el puntaje promedio del colegio (global y por materia) con los promedios del departamento y del país (benchmarks), para que pueda ver el desempeño en un contexto amplio.
  • Distribución por Niveles de Desempeño: Mostramos cuántos estudiantes se ubican en cada nivel (de 1 a 4, y de A- a B+ para inglés). Esto le permite evaluar la distribución de la calidad más allá del simple promedio.
  • Evolución Histórica: Una gráfica que muestra la tendencia del puntaje global promedio del colegio a lo largo de los últimos años (comparando periodos equivalentes, ej. 2024-1 vs 2023-1), ideal para seguir el progreso en el tiempo.
  • Distribución de Puntajes: Un histograma que visualiza cómo se agrupan los puntajes de los estudiantes, revelando si los resultados son consistentes, dispersos o se concentran en rangos específicos.
  • Lista Detallada de Estudiantes: Un listado de los resultados individuales (anónimos) de los estudiantes, ordenados por puntaje, que incluye su percentil global, género y nacionalidad, tal como se encuentra en los datos públicos del ICFES.
¿Cómo Funciona Minerva? (La Pila Tecnológica)

Para los interesados en los detalles técnicos, Minerva está construida como una aplicación web moderna que sigue una arquitectura cliente-servidor. A continuación, se detalla el rol de cada componente:

  • El Backend (Python, Flask y SQLite): Es el motor de la aplicación, invisible para el usuario final pero encargado de todo el trabajo pesado.
    • Procesamiento Inicial (Script create_database.py): Antes de que la web esté en línea, un script de Python lee los archivos de texto crudos del ICFES. Realiza la limpieza, normalización (ej. unificar "BOGOTA D.C." y "BOGOTA"), y pre-calcula todos los promedios (benchmarks) nacionales y departamentales.
    • Base de Datos (SQLite): Toda esta información procesada se almacena en una base de datos SQLite. Se eligió esta tecnología por ser extremadamente eficiente, rápida y portable, ideal para manejar grandes volúmenes de datos en un entorno de hosting económico como PythonAnywhere.
    • API (Flask): Un micro-framework web llamado Flask expone los datos a través de una API. Cuando el usuario hace una selección, el frontend consulta esta API, y Flask se encarga de buscar en la base de datos y devolver únicamente la información solicitada en formato JSON.
  • El Frontend (HTML, CSS y JavaScript): Es todo lo que usted ve e interactúa en su navegador.
    • HTML: Proporciona la estructura de la página: los títulos, las listas, las tablas y los contenedores.
    • CSS (Pico.css): Se encarga de todo el estilo visual. Utilizamos el framework ligero Pico.css para asegurar un diseño limpio, moderno y adaptable a móviles y escritorio.
    • JavaScript: Es el responsable de la interactividad. Se ejecuta en su navegador para comunicarse con el backend. Cuando usted selecciona un periodo, JavaScript solicita la lista de departamentos a la API de Flask y actualiza el menú desplegable. Al elegir un colegio, obtiene los datos y utiliza la librería Chart.js para dibujar las gráficas que ve en pantalla.

En resumen, Python y SQLite realizan el trabajo pesado de preparación de datos una sola vez, y Flask los sirve eficientemente a través de una API. El código JavaScript de su navegador consume estos datos para crear una experiencia de usuario rápida e interactiva, permitiéndole explorar estos complejos datos de manera sencilla.
